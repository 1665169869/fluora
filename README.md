## 快速开始

1. 安装依赖
```bash
flutter pub get
```

2. 运行
```bash
flutter run
```

## 技术选型
- flutter < 4 && >= 3.29.0
- dart < 4 && >= 3.7.0
- getx
- permission_handler
- webdav_client
